Reel Counter

GET AN APK WITHOUT ANDROID STUDIO (GitHub Actions)
1. Create a free GitHub repo and upload the CONTENTS of this folder (settings.gradle.kts must be at the repo root, along with the .github folder).
2. Open the repo's Actions tab. The "Build APK" workflow runs automatically (or click Run workflow).
3. When it finishes (about 3-5 min), open the run and download "ReelCounter-APK" from Artifacts. Unzip it to get app-debug.apk.
4. Copy the APK to your phone and install it (allow "install unknown apps").

OR USE ANDROID STUDIO
File > Open this folder, wait for sync, Build > Build APK(s).

AFTER INSTALLING
Open the app > "Open Accessibility settings" > Reel Counter > turn on.
(Android 13+: App info > 3-dot menu > "Allow restricted settings" first.)
Drag the small pill to move it.
